# HALL 666 · Cape of No Hope

Halloween scavenger hunt device for 31 October. Everything is in `index.html`: the HALL 666 home screen and all eight stop games.

## Put it online (GitHub Pages)
1. Upload `index.html` to the root of a GitHub repository.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Open the site, tap the lock (PIN 1031) → Print QR codes. Print them from the live site so each code points at your address.

## Stops
Each QR code opens `index.html?stop=<id>`:
dewaal, pump, tomb, percys, mannenberg, broomstick, nightwatch, tiki

Camera, microphone and motion need the site served over HTTPS (GitHub Pages is).
